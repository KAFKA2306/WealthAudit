# 💰 WealthAudit - Your Personal CFO

**家計簿から「資産形成」を可視化する、次世代の個人財務ダッシュボード**

WealthAuditは、日々の家計簿データから貸借対照表（BS）と損益計算書（PL）を自動生成し、あなたの財務状態を企業会計のように精緻に分析・可視化するシステムです。

---

## ✨ 主な特徴 (Key Features)

### 📊 1. 財務諸表の自動生成
日々の「収入」「支出」そして「資産残高」のCSVデータから、複式簿記に基づいた**BS（貸借対照表）**と**PL（損益計算書）**を毎月自動で作成します。

### 📈 2. 30年資産シミュレーション
現在の資産状況と収支トレンドに基づき、向こう**30年間の資産推移を予測**します。設定したリターン率やインフレ率を加味した、リアルな将来設計が可能です。

### 🔥 3. FIRE達成度の可視化
経済的自立（Financial Independence）に向けた進捗をリアルタイムで追跡。「生活費の何倍の資産があるか」を示す**FI Ratio**を、過去・現在・未来（予測）の3つの視点で表示します。

### 💹 4. プロ仕様の投資分析
単なる損益管理だけでなく、市場ベンチマーク（S&P 500など）と比較した**α（超過リターン）**を計算。あなたの投資パフォーマンスを客観的に評価します。

---

## 🖥️ ダッシュボード機能 (Dashboard)

直感的なHTMXベースのWebインターフェースで、6つの重要な視点から財務状況を俯瞰できます。

| グラフ | 機能概要 |
| :--- | :--- |
| **Net Worth Trend** | 純資産の推移を「流動資産」「リスク資産」「年金資産」に分けて積層表示。資産の質的変化を一目で把握できます。 |
| **Cash Flow** | 収入、支出に加え、「投資損益」を含めたトータルのキャッシュフローを可視化。真の貯蓄力を測ります。 |
| **Asset Allocation** | 最新の資産配分（ポートフォリオ）をドーナツチャートで表示。リスク資産への配分比率をチェックできます。 |
| **Financial Ratios** | 「貯蓄率」や「リスク資産比率」など、健全な家計運営に必要な重要指標（KPI）をモニタるします。 |
| **Investment Returns** | 月ごとの投資リターンをベンチマークと比較。市場平均に勝てているかどうかが分かります。 |
| **FI Ratios** | FIRE達成に向けたマジックナンバー（例：資産25倍）に対する現在の到達度をトラッキングします。 |

## 🚀 はじめ方 (Getting Started)

ご自身のPC（ローカル環境）で安全にデータを管理・運用できます。

### 必要要件
- Python 3.10+
- [uv](https://github.com/astral-sh/uv) (パッケージマネージャー)

### 3ステップで開始
1. **Clone**: リポジトリをダウンロード
2. **Sync**: `uv sync` で環境構築
3. **Run**: `task serve` でダッシュボード起動

詳細は [README](../README.md) をご覧ください。
